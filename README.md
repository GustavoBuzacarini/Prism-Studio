# Prism Studio

Site institucional da **Prism Studio**, um estúdio digital premium focado em design autoral, experiências interativas, animações e tecnologia 3D.

> Status: concluído.

## Sobre o projeto

O projeto apresenta a identidade, a proposta e os trabalhos recentes da Prism Studio por meio de uma experiência visual imersiva. A interface combina vídeos de fundo, transições controladas pelo scroll e um elemento 3D interativo em forma de diamante.

## Principais recursos

- Preloader animado com indicador de progresso;
- vídeos de fundo no hero e no rodapé;
- transições e animações vinculadas ao scroll;
- textos animados com efeitos de desfoque e revelação;
- cards de projetos com abertura progressiva e transição de saturação;
- modelo 3D renderizado em tempo real;
- iluminação do objeto 3D baseada em ambiente HDRI;

## Tecnologias

- HTML5;
- CSS3;
- JavaScript;
- [GSAP](https://gsap.com/) com ScrollTrigger, ScrollSmoother e SplitText;
- [Three.js](https://threejs.org/) com GLTFLoader.

As bibliotecas externas são carregadas por CDN, portanto é necessário ter conexão com a internet para executar todas as animações.

## English

**Prism Studio** is a premium digital studio website focused on custom design, interactive experiences, animation, and 3D technology.

> Status: completed.

## About the project

The project showcases Prism Studio's identity, positioning, and recent work through an immersive visual experience. The interface combines background videos, scroll-driven transitions, and an interactive diamond-shaped 3D element.

## Key features

- Animated preloader with a progress indicator;
- background videos in the hero and footer sections;
- scroll-driven transitions and animations;
- animated text with blur and reveal effects;
- project cards with progressive expansion and saturation transitions;
- real-time 3D model rendering;
- HDRI-based lighting for the 3D object;

## Technologies

- HTML5;
- CSS3;
- JavaScript;
- [GSAP](https://gsap.com/) with ScrollTrigger, ScrollSmoother, and SplitText;
- [Three.js](https://threejs.org/) with GLTFLoader.

External libraries are loaded from CDNs, so an internet connection is required for all animations to work.
